# Getting help

- **Questions and ideas:** ask in
  [Conn3x Discussions](https://github.com/conn3xorg/conn3x/discussions).
  It's the one place for Conn3x and every circuit, so you'll find earlier
  answers there too.
- **A bug in a circuit:** open an issue on that circuit's repo, such as
  `conn3xorg/circuit-postgres`.
- **A bug in Conn3x itself:** if it happens with any configuration, not just
  one circuit, [open an issue on Conn3x](https://github.com/conn3xorg/conn3x/issues/new/choose).
- **Security problems:** see the
  [security policy](https://github.com/conn3xorg/.github/blob/main/SECURITY.md).
  Please don't post them in public.

Not sure whether it's the circuit or Conn3x? File it on the circuit. We'll
move it if it belongs elsewhere.
